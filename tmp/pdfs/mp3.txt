     In this project you will design and code a class called SequenceableCollection that stores integer numbers in
C++. This class combines the advantage of arrays (e.g., direct element access) with the advantage of linked lists
(e.g., variable size). This class initially allocates a region of 8 contiguous integer elements, none of which are
initially used as sequence elements (i.e., integer values). (Use a dynamically allocated integer array for this initial
region.) You can insert up to 8 integers in this initial region of the sequence. When a ninth integer should be
inserted but the initial region is full, a new region of double size (e.g., 16 elements) is allocated dynamically; the
data originally stored in the sequenceable collection will be copied to the new region and the ninth element will be
added.
     Your implementation must satisfy the contiguous storage requirement. The elements inserted in Sequence-
ableCollection must be stored contiguously in the allocated storage region at all times and regardless of region
size.
     To implement class SequenceableCollection, declare two instance variables, called start and end, to indicate
the starting and ending indices of region positions that are used for storing elements added to the sequence. Initially,
set start to 3 and end to 2 to indicate that the SequenceableCollection contains no elements. When the first
element is added, place the element at position 3 in the region and increment end to 3. (This will indicate that
the collection holds just one integer at position 3.) Next, you may add an element at position 2 or 4, depending on
your choice, and so on. Your SequenceableCollection class must specifically support the following protocol. (All
the methods below should be public, unless explicitly stated otherwise.)
